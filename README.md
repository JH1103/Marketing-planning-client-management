Marketing Planning & Client Management Application

Overview

A Python desktop application developed to support client profile and appointment management for marketing activities.

Features

Client Management
- Client login
- Client profile management
- View and update profile information
- Client appointment management
- Appointment history

Appointment Management
- Create appointments
- Update appointments
- View appointment information
- Appointment status management
- Check-in functionality

Administrator Management
- Administrator login
- Admin account management
- Client profile management
- Appointment management
- Search functionality
- Audit/history management

Technologies
- Python
- Tkinter
- JSON
- Object-oriented programming concepts
- Data structures
- Functions
- Input validation
- Date and time processing

Project Purpose

The application was developed to demonstrate Python programming, GUI development, client data management, appointment management, validation, and data processing.
